## 2. Recommendation: *Transfusion Medicine* first, *Vox Sanguinis* as the backup

**Why *Transfusion Medicine*:**

1. **Room for an honest paper with a planned analysis.** A null result under a written plan needs space for the calibration result, the deviations table and the limits. *Transfusion Medicine* allows 5,000 words with 6 display items and 60 references. *Vox Sanguinis* counts references, tables and legends inside its 5,000. v10 would sit right at that limit, leaving no room for anything reviewers ask to add.
2. **Clear preprint route.** It explicitly allows a preprint on a non-commercial server before submission, so medRxiv first, then journal, works.
3. **Easier first submission.** Free-format submission (any consistent reference style) means the current Vancouver build can go in as it is.
4. **Lower optional APC** (USD 4,070 vs 4,250). Publishing without open access is free at both.

**Where *Vox Sanguinis* is stronger:** inventory management is named in its scope, and it does not cap display items or references. If *Transfusion Medicine* declines, v10 can be cut for *Vox* by: (a) moving Table 3 (deviations) to the supplement; (b) checking the all-in count (text, abstract, references, tables and legends) and trimming if it goes over 5,000; (c) renaming the abstract headings and removing abbreviations from the abstract; (d) adding 3 highlights; (e) switching to Arial 12 pt at 1.5 spacing.

**Honest odds:** neither page says it welcomes null results. A null under a written plan, with a failed calibration and a plan registered only after the analyses, is honest and useful, but an editor may see it as low novelty. The paper's case is the method (a written analysis plan, a calibration check that was reported even though it failed, and a second site), not a win for forecasting.
