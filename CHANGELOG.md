## 0.13.0 — 2026-11-25

Archives the one confirmatory run of 25 November 2026, copied from
`dixonlj/transfusion-inventory-advisor` commit
`a85902ba646f6054e187e8b5b154904a137e2d1e`. The code that ran is
`5f079cee3da55e9727f204f74aa2db45fe8654ad`. Existing paper and Study 2
files are unchanged. This entry does not create a release.

- The primary comparison did not show a difference. SARIMA order-up-to versus
  a yearly 90th-percentile par differed by −1.6 units a year (95% interval
  −4.2 to 0, p 0.081).
- Because that result was not shown, the network test and the Holm family are
  descriptive only.
- The registration is https://osf.io/tuj9p (DOI 10.17605/OSF.IO/TUJ9P). OSF no
  longer accepts new projects, so the results are archived in this repository
  for a later Zenodo deposit.
- Run files: `results/confirmatory_2026-11-25/`. Write-up:
  `docs/CONFIRMATORY_RESULTS_2026-11-25.md`. Deviations:
